PDF → PDF/A-style

Add a PDF and export a PDF/A-style archival version: encryption stripped, archival XMP metadata added. Nothing leaves your browser.

Honest limits: this is not a certified PDF/A conversion. There is no way to validate real PDF/A compliance in a browser — no ICC color profile is embedded, and fonts already in the source PDF that aren't embedded (e.g. the built-in "Standard 14" fonts) stay that way; we only report which ones. Treat this as a best-effort archival export, not a guarantee an archive system will accept.
